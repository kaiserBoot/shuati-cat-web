一、資料處理原則

刷題貓以裝置內儲存學習資料為主要設計，不要求您註冊刷題貓帳號。我們不會自動將您的逐題作答、錯題、收藏或學習分析上傳至我們的伺服器，也不出售這些學習資料。

訂閱付款、題庫下載及廣告涉及平台或第三方服務的連線與資料處理，詳見以下說明。

二、裝置內的學習資料

為提供練習、複習與學習分析，App 會在您的裝置儲存作答選項、對錯、作答時間、測驗紀錄、錯題、收藏、學習統計、解析解鎖紀錄及操作偏好。這些資料用於呈現學習成果、安排練習及保留使用設定。

我們不會僅因您使用上述功能，就取得裝置內的完整學習資料庫。若您主動將資料透過分享功能或客服管道交給我們，則依本政策的分享與客服說明處理。

刷題貓目前不提供自有雲端備份或跨裝置同步。作業系統可能依您的裝置及雲端備份設定備份 App 資料，該處理由系統服務提供者負責，並適用其隱私權政策。

三、訂閱與付款

iOS 版本的訂閱購買、付款、續訂及退款由 Apple 的 App Store 機制處理。我們不會取得您的完整信用卡號或付款密碼。

App 會透過 Apple 提供的購買機制確認訂閱資格，並在裝置保存訂閱是否有效、到期時間及必要的購買狀態資訊，用於開放訂閱功能、還原購買及判斷離線使用資格。Apple 可能向開發者提供銷售、財務或彙整報表；Apple 對帳號、付款及交易資料的處理，請參閱 Apple 隱私權政策。

四、廣告與第三方廣告服務

非訂閱版本可能顯示橫幅、插頁式或由您主動選擇觀看的獎勵廣告；實際形式依 App 提供的功能而定。有效訂閱期間不顯示橫幅與插頁式廣告，查看訂閱權益內的詳細解析也不需觀看獎勵廣告。

廣告服務會連線，可能由服務商處理必要的裝置、網路及廣告互動資料。首發版本的服務商與處理範圍如下：

  • 廣告服務商：〔正式採用的服務商及 SDK 名稱〕。
  • 處理的資料類別：〔依實際 SDK、設定及官方揭露列出；例如 IP 位址、裝置與系統資訊、廣告曝光／互動、診斷資訊；未使用的項目不得列為已蒐集〕。
  • 使用目的：〔依實際設定列出廣告提供、成效衡量、防詐欺等目的〕。
  • 廣告模式與兒少設定：〔是否僅使用情境式或非個人化廣告、適齡限制、兒童導向處理及適用的同意方式〕。
  • 跨 App／網站追蹤：〔是否涉及追蹤、是否存取廣告識別碼，以及適用的系統授權機制〕。
  • 處理地區、接收對象及保留期間：〔服務商及其受託者的實際範圍，並附對應說明連結〕。
  • 隱私權政策與資料管理方式：〔服務商官方連結及使用者可操作的退出／刪除方式〕。

如依法或平台規範需要授權，我們會在相關資料處理開始前取得必要授權；拒絕授權的影響會在當時說明。政策更新或繼續使用 App 本身，不會取代依法應另行取得的同意。

五、題庫下載與平台診斷

iOS 補充題庫透過 Apple 提供的資源下載服務取得。下載時裝置會與 Apple 服務連線，由 Apple 依其政策處理連線與服務所需資料；這不代表您的作答紀錄或完整學習資料庫會傳給 Apple。

App 會在本機保留有限的題庫下載診斷紀錄，包括下載時間、題庫識別與版本、下載階段、進度、耗時、經過濾的錯誤資訊，以及 App 版本、系統版本與裝置型號等。紀錄不包含題目內容、作答內容、照片、完整資料庫或認證憑證。

診斷紀錄設有七天及總量 2 MB 的輪替限制，於 App 執行紀錄維護時清理舊資料。只有您主動選擇「分享診斷紀錄」並透過系統分享選單傳送時，收件者才會取得您分享的檔案，App 不會自動將該檔案傳給我們。

此外，Apple 可能依您的裝置設定與平台機制，處理當機、診斷或彙整使用資訊，並向開發者提供相關報告。這與 App 自行上傳您的學習紀錄不同；請參閱 Apple 的 App 分析與隱私權說明。

六、主動分享與聯絡客服

您可以主動將測驗結果、學習分析摘要或診斷紀錄交給系統分享選單，再選擇接收對象。分享圖可能包含學習表現及測驗統計，分享前請確認內容與對象。接收 App 或服務對資料的處理，適用其各自的政策。

若您透過電子郵件聯絡我們，我們會取得您提供的電子郵件地址、訊息、附件及處理問題所需資訊，僅用於回覆、排查問題、處理您的請求或履行法定義務。不提供必要資訊時，可能無法完成特定問題的查核，但不影響與該請求無關的基本練習功能。

請避免提供學生姓名、學校、班級、座號、聯絡方式或其他不必要的個人資料；如需附上截圖，請先遮蔽無關資訊。

七、資料保存、地區與接收對象

裝置內的學習資料原則上保留於您使用 App 的裝置，直到您透過已提供的功能刪除，或由系統移除 App 資料。刪除題庫可能一併影響相關作答、錯題或收藏，請先閱讀刪除確認畫面的範圍說明。

客服往來資料僅於處理請求、必要的後續查核及法令要求所需期間保存；目的消失且無其他合法保存事由時，予以刪除或去識別化。處理對象限營運者、必要的支援人員及提供郵件等基礎服務的受託者；依法提出的要求則依適用法律處理。

客服郵件、Apple、廣告服務及網站代管可能涉及境外處理。客服使用的服務商、處理地區與保留安排為：〔補入實際郵件服務商、可能處理地區及保留安排〕。各平台及廣告服務商的處理範圍依本政策所列連結及揭露說明。

八、您的選擇與權利

您可依適用法律請求查詢、閱覽、取得複製本、補充或更正、停止蒐集處理利用，以及刪除我們持有的個人資料。請透過本政策的聯絡信箱提出，我們會在必要範圍確認身分並依法回應；若依法須繼續保存部分資料，會說明理由。

僅存在您裝置、我們未持有的資料，需由您在裝置操作，我們可以提供操作協助。移除 App 與其資料通常會移除本機紀錄；iOS 的「卸載 App」可能保留資料。裝置備份、相簿原檔、已分享給他人的副本及平台交易紀錄，需分別向相關服務管理。刪除 App 不會自動取消訂閱。

九、兒童與未成年使用者

刷題貓提供學生學習使用，不要求學生提供真實姓名、學校或聯絡資料。未成年使用者請與家長或法定代理人一同閱讀本政策；訂閱購買及依法需要的同意，應由有權同意的人完成。

如您認為我們取得了不應持有的兒童個人資料，請透過聯絡信箱告知，我們會查核並依法處理。兒少廣告的實際資料處理及限制，另見第四節。

十、政策網站與外部連結

本政策與使用條款網站使用 GitHub Pages 代管。造訪網站時，GitHub 會為安全目的記錄訪客 IP 位址，詳見 GitHub Pages 資料蒐集說明 與 GitHub 隱私權聲明。

網站中的外部連結會前往其他服務，其資料處理適用各服務的政策。

十一、政策更新

若功能、服務商或資料處理方式變更，我們會更新本政策及日期；重大變更會透過 App 或適當方式通知。需要另行告知或取得同意的事項，會在相關處理開始前完成。
